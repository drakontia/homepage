# ChaosZeroNightmareDeckBuilder

- GitHub: https://github.com/Drakontia/ChaosZeroNightmareDeckBuilder
- [使い方](/apps/chaos-zero-nightmare-deck-builder/usage)

## 概要

デッキビルダーは、カオゼロのデッキ（ゲーム内で言うところのセーブデータとして表示されるもの）を自由に構築できるサイトです。
使いやすい様に、なるべくゲーム内に近いような見た目、操作性にしてあります。
スマホでも一応使えますが、見た目の調整がまだの部分があり見にくいこともありますが、ご容赦ください。
（デッキエディターになっていますが、デッキビルダーの方が正しいかと思い、いずれ改名する予定です。）

使用用途としては、カオスに潜る前にあらかじめデッキを考えておいて備忘録にしたり、こういうデッキが出来ましたというのを共有したりなどにご利用して頂ければと思います。
キャラ解説などの配信にも使って問題ありませんので、どうぞたくさんご利用ください。
