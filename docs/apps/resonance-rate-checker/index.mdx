# ResonanceRateChecker

- GitHub: https://github.com/Drakontia/ResonanceRateChecker
- ツール本体: https://resonance.drakontia.com/
- [使い方](/apps/resonance-rate-checker/usage)

## 概要

商品の売値情報（相場）を表示するサイトです。このサイトを活用することで、日々の相場チェックの手間から解放され、よりスムーズに売却を行えるようになります。

なお、当サイトで表示している価格・取引情報は、『レゾナンス：無限号列車』運営チームより正式に提供された公式APIを利用して取得しているものであり、非公式手段や不正なアクセスは一切行っていません。
