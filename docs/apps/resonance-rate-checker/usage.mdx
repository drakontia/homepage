# 使い方

### ①トップページ

[リンク](https://resonance.drakontia.com/)からサイトにアクセスする。

以降の作業では、PC・スマートフォンのどちらでもプライベートモードを使用しないこと。
プライベートモードでは設定が保存されないためである。

なお、アプリ版の導入も推奨される。iOS・Androidともに、ブラウザのメニューから「ホーム画面に追加」または「アプリとして追加」を選択することで導入可能である。

### ②商品一覧を選択

『ホーム』タブの右隣にある『商品一覧』タブを選択する。

### ③商品名を検索

入力フォームに売値を知りたい商品名を入力する。

### ④駅を選択

デフォルトでは、その時点で最も高い駅における売値、%、価格変動傾向が表示される。

ここで『駅を選択』タブを開き、売値を確認したい駅を選択する。
商品を最も高く売れる駅（原産地から最も遠い駅）を中心に選択するとよい。

### ⑤お気に入り登録

登録したい商品名・駅名が正しいことを確認したら、右上の★マークをタップしてお気に入り登録する。

### ⑥任意の商品をお気に入り登録する

手順②〜⑤を繰り返し、任意の商品をお気に入り登録する。

### ⑦ホーム画面で確認

『ホーム』タブ → 『商品一覧』（デフォルトで選択される）で、お気に入り登録した商品の売値、％、価格変動傾向を確認する。

### ⑧日常的に価格情報を確認する

お気に入り登録が完了したら、以後はサイトへアクセスするだけで、登録した商品の価格情報をすぐに確認できる。

なお、お気に入りは端末/ブラウザごとに管理されるため、PC・スマートフォンなど各端末/各ブラウザで最初に一度だけ登録作業が必要となる。

## 価格表

主にPC環境で、お気に入り商品を中心に網羅的に閲覧することを目的としている。
商品一覧と同様に、価格表のタブから商品を検索してお気に入りに登録することで、ホーム画面に追加可能。

表示方法は「価格」と「%」から任意に選択できる。各駅の都市声望を上げる目的でセンター品を売却する際に便利。

## 注意点

- 価格情報は自動で更新されるが、最低でも10分間の間隔が空くように制限されている。自動更新されない場合は、ブラウザをリロードすることで更新を反映することが出来る。
- 実際のゲーム内での価格変動に対し、サイト上の更新が遅延する場合がある。商品の売却に1分1秒を争う状況では、価格情報を参考にあらかじめ該当駅で売却準備を進めておき、最終的にはゲーム内で%を確認するとより確実である。
